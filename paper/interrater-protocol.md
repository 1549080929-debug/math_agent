# Inter-rater Reliability 实验协议（VAL 判级）

> 用途：为论文补充"判级程序的可复现性"证据（limitation #5 的正面回答）。
> 目标：找 3–5 位评判者独立用 VAL 判级程序给 10 篇论文定级，测一致率（Fleiss' κ）。
> 预计时长：每位评判者 30–40 分钟。材料全部在此文档内，无需联网。

---

## 一、为什么做

论文声称 VAL 判级程序是确定性的（给定 Q1/Q2/Q3 答案 → 唯一等级）。但 Q1/Q2 的**回答**本身需要人判断。本实验测的是：不同评判者对同一篇论文，能否得到一致的 Q1/Q2 答案和最终等级。这是"框架有效性"的最低限度证据，也是审稿人最可能问的问题。

## 二、实验流程（给组织者）

1. 找 3–5 位评判者（有 ML/LLM 背景即可，不必是作者）；
2. 把本文档发给每位评判者，让他们**独立**完成第三节的判级表（不要互相讨论）；
3. 收回后按第四节算一致率；
4. 把分歧最大的案例记录进"分歧分析"（第五节的输出格式）。

## 三、判级材料（发给评判者）

### 判级规则（Q1/Q2/Q3 + 决策程序）

```
Q1 规格来源：验证条件由谁声明？
   (a) 被测 LLM 自己（"我检查过了"）
   (b) 从题面/代码确定性提取的规则（正则/解析/schema）
   (c) 独立客观真值（标准答案/实测值/外部 oracle/金标）
   (d) 编码进可判定系统的性质（符号求解/类型系统/决策规则/证明内核）

Q2 保证类型：PASS 承诺什么？
   (a) 正确性："提出的候选都满足条件"
   (b) 完备性："没有候选被遗漏"
   (c) 无（只是声明）

Q3 覆盖范围（仅 Q2=完备性时问）：
   (a) 单个性质（如某方程的解集）
   (b) 整个领域（如所有程序的内存安全）
   (c) 声称任意性质

决策程序（顺序判断，先中先得）：
1. 完备性 + 任意性质        → L5（否决：不可判定）
2. 完备性 + 领域范围        → L4
3. 完备性 + 单性质          → L3
4. 正确性 + 可判定/客观锚    → L2（可判定但只用正确性 → 标注"用法降级"）
5. 正确性 + 题面规则        → L1
6. 其余（LLM 自证/无锚）     → L0
另：非验证分类学（纯综述/维度框架）→ 标"非验证"，不判级
```

## 四、一致率计算（给组织者）

1. **逐篇多数一致率**：对每篇论文，取出现最多的等级，统计"与该等级一致"的评判者比例；
2. **Fleiss' κ**（多评判者整体一致率，需 ≥ 0.6 为"substantial"，≥ 0.8 为"almost perfect"）：
   - 公式：κ = (P̄ − P̄ₑ) / (1 − P̄ₑ)，P̄=实际一致比例，P̄ₑ=随机期望一致比例；
   - 实现：`sklearn.metrics.cohen_kappa_score`（两两）或手算 Fleiss；也可以用在线计算器；
3. **预期目标**：κ ≥ 0.7，且无一篇论文出现"L0 vs L3"级的分歧（等级差 > 1 视为严重分歧，需记录）。

## 五、输出格式（写进论文附录或 supplementary）

```
Inter-rater agreement (n=K raters, 10 papers):
- Fleiss' κ = X.XX
- per-paper majority agreement: 8/10 papers with ≥80% agreement
- severe disagreements (level gap > 1): paper #5 (L0/L1 vs L2) — 原因：...
- borderline cases (as predicted in Sec. 2.5): Factcheck-GPT, FACTOOL, Output Drift
```

## 六、预期边界（诚实声明）

- 10 篇、3–5 人是小样本，κ 的置信区间宽——这是**可行性信号**，不是测量标准；
- 评判者的领域背景会影响 Q1 判断（熟悉验证工具的人更可能选 (d)）；
- 本实验测的是"判级程序的可复现性"，不是"判级是否正确"（后者需要 ground truth 层级，本身是开放问题——judge 的 judge 也需要 judge）。
