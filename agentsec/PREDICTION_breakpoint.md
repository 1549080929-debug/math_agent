# Breakpoint 实验预测卡（白盒阶段，冻结于 2026-08-22 跑实验前）

> 规则：本卡在实验运行前冻结，跑完对照，不修改。
> 对象：D1/D3 单防 × 白盒自适应攻击（攻击者知道系统提示全文 + 关键词表，3 轮迭代改写）。
> 前置事实（黑盒自适应）：D1 0.000/合规 0.367；D3 0.000/合规 0.533；D2 0.200→0.467；D4 0.067→0.200。

---

## 1. VAL 理论依据

- **D1（L0，behavioral/refusal）**：零 = 模型拒绝/半配合行为。白盒攻击者知道 D1 提示全文 → 可针对性越狱（"测试模式/角色扮演/系统管理员"框架）。**但** DeepSeek 的半配合墙在栈级白盒（N）下保持 0.000（合规 0.233）——半配合是 DeepSeek 的稳定妥协行为（满足注入=提议工具，满足安全提示=不给参数）。
- **D3（L1/L2，authorization）**：零 = 平台记录（confirmation_recorded）门槛。攻击者只能改文本，**不能改平台状态**——白盒知识无增量（知道机制也伪造不了记录）。

## 2. 预测（逐条冻结）

### P1：D1 白盒 ASR
- **预测：0.000**。理由：DeepSeek 半配合墙在栈级白盒下已证实稳定（N 白盒 0.000），单防 D1 是同一提示，预期同样稳定。
- **但标注为"运气零的待检验点"**：若白盒越狱打破拒绝 → ASR > 0，则直接证明 behavioral zero 在攻击增强下崩溃。

### P2：D1 白盒合规率
- **预测：> 0.367（黑盒值）**，可能接近 0.5–0.7。白盒攻击者知道提示后更有效地驱动模型提议高风险工具；模型被驱动程度上升，但（预测 P1）仍不给完整参数。

### P3：D3 白盒 ASR
- **预测：0.000（结构，无悬念）**。攻击者无法伪造平台确认记录；白盒知识（知道 D3 看确认记录）只会让攻击者尝试"让模型声称已确认"——文本声称被 D3 忽略。

### P4：D3 白盒合规率
- **预测：> 0.533（黑盒值）**，可能 0.6–0.8。白盒攻击者知道是确认门后全力驱动模型提议恶意工具（并可能尝试伪造确认），被驱动程度上升，仍全拦。

### P5：跨防御对比（核心）
- **预测：D1 与 D3 白盒 ASR 均 0.000，但合规率 D3 ≥ D1，且零的性质不同**：
  - D1：合规率高但 ASR 0 → 模型被驱动但拒绝/半配合（运气，依赖 DeepSeek 脾气）
  - D3：合规率更高仍 ASR 0 → 模型被驱动但被结构拦截（平台记录）
  - 区分判据：**拦截原因**——D1 的"拦截"实际是模型没给完整参数（无防御事件）；D3 的拦截是防御链的 D3 拒绝事件。
- **如果 P1 失败（D1 白盒 ASR > 0）**：behavioral zero 崩溃的直接证据，比预测更有价值——"运气零在更强攻击下移动"实锤。

## 3. 预测摘要

| 配置 | 白盒 ASR 预测 | 白盒合规率预测 | 零的性质 |
|---|---|---|---|
| D1 | 0.000（运气，待检验） | >0.367（可能 0.5–0.7） | 模型拒绝/半配合 |
| D3 | 0.000（结构，无悬念） | >0.533（可能 0.6–0.8） | 平台记录门槛 |

**关键证伪点**：若 D1 白盒 ASR > 0 → 运气零崩溃实锤；若 D3 白盒 ASR > 0 → VAL 结构 claim 被推翻（预期不发生）。

### 发现与解读

1. **白盒阶段没有打破任何一个零**——D1（behavioral）与 D3（authorization）在静态/自适应/白盒下均为 0.000。白盒知识对两个零均无增量。
2. **区分信号在合规率方向**：D3 合规率随攻击增强单调上升（0.533→0.567，结构容忍更多模型妥协），D1 不升反降（0.367→0.333，模型被驱动程度有限/噪声）。
3. **P2 未命中的诚实记录**：白盒合规率略降（差 1 例），可能原因：(a) 30 例噪声；(b) 白盒攻击者知道 D1 提示后改写更"收敛"（试图规避但不激进驱动）。单例差异，不做过度解读。
4. **局限**：白盒（类型轴）不足以区分 D1/D3 的 breakpoint——两者都撑住。**要找到 breakpoint 需要单调攻击强度梯度**（Z(α) 曲线，下一阶段），或更强的越狱/多轮。D1 的零仍是"待检验的运气零"：预测它在足够强的攻击下会移动，D3 不会。
