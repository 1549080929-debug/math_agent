## 一、我们对贵团队工作的理解

贵团队发布的 JADE 7.0 是智能体安全领域的重要工作：**JADE-MCP-CLS 分类**（首个针对恶意 MCP Server 的系统性风险分类，6 大类 33 小类）和配套的近百个恶意 Server 实例集合，系统性地覆盖了直接投毒（工具描述注入）与间接投毒（外部资源污染）两种攻击。贵团队基于 Cursor 环境对 8 款主流模型的评测（直接投毒平均 ASR 83.0%、间接投毒 80.3%）清楚地表明：**当前 LLM 内生防御手段对 MCP 生态投毒攻击普遍失效**。这一结论与我们在自研测试床和 AgentDojo 官方基准上的观察高度一致。

## 二、我们的工作：一个解释"为什么"的框架

我们提出了 **VAL（Verification Autonomy Levels，验证自主等级 L0–L5）** 框架（arXiv:2608.19009），按"验证/防御规格的来源"给防御方案分级：

- **L0**：模型自述/自我评估——"运气"防御，换攻击、换模型、换基准，零会移动
- **L1**：确定性规则（如关键词过滤）——可被改写绕过
- **L2**：客观真值（正确性）——分布内有效，分布外失效
- **L3/L4**：可判定系统（沙箱、信息流、确认门）——结构保证，与模型行为无关

核心论点是：**防御失败的方式 = 其锚失效的方式**。我们在自研测试床（~5400 次调用）和 AgentDojo 官方基准上验证了这一点：一个"确认门 + 参数沙箱"的 VAL 选型栈在 AgentDojo 上 0% ASR 且零 utility 损失，而"提示加固 + 关键词过滤"的直觉栈同为零但机制上是模型运气。
