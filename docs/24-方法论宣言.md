# 方法论宣言：黑盒、来源与边界

> 日期：2026-08-22 · 项目方法论的总纲 · 源起于审稿演练、构造实验、AI-assisted research 全过程的反省

---

## 1. 不变量

**当一个系统的内部不可直接获得时，不要执着于打开它；先找到它的外部可作用面、可观测响应、证据锚点和失败边界。**

```
Outcome → Response → Provenance / Anchor → Guarantee → Failure Boundary
```

一个不可直接观察的系统，只要能够：施加可控刺激 → 记录响应 → 保留 trace → 验证 external effect → 研究稳定性 → 找到 failure boundary，就从"神秘对象"变成**可实验、可复现、可证伪的对象**。

## 2. 不变量在不同层级的出现

| 层级 | 它解释什么 |
|---|---|
| Verification | 一个 verdict 凭什么有这样的 guarantee（VAL 的锚） |
| Agent security | 两个相同的 zero 为什么不是同一种 zero |
| Z(α) | zero 在压力下如何运动（稳定性曲线） |
| Execution funnel | zero 在执行链的哪一层形成（断开层） |
| AI-assisted research | 一个 AI 产生的科学结果，凭什么值得相信 |
| 黑盒科学 | 不必打开黑盒，才能科学地研究黑盒 |

## 3. 三处精确化

1. **不是"不打开黑盒"，而是"有序打开"**：外部黑盒观测是主证据；当外部不足以区分时，才审慎引入**最小化的内部分辨器**（如 execution funnel 的中间变量），且内部变量本身必须来自 trace 记录（可被 forensic audit），而非模型自述。D1/D3 的 Z(α) 重合（纯外部）→ funnel（内部分辨）正是这一流程。
2. **"科学不需要终极裁判"的精确表述**：终极裁判不可达（与 VAL 的 L5 同构），所以每层诚实声明自己的 anchor/scope/guarantee/residual uncertainty 是唯一可行的完备性策略。
3. **VAL 的锚就是这个不变量的实例化**：验证方案的锚 = 验证规格的来源（外部可作用面）；"裁判的裁判"是递归层的实例化。因此"不断换研究对象结构仍然成立"不是偶然——VAL 从一开始就按此结构设计。

## 4. 失效边界（适用条件）

这个方法论不是无条件成立的，其适用条件本身值得研究：

- 外部可作用面不存在或不可控（无法施加刺激的纯被动系统）
- 响应不可观测或观测成本过高
- failure boundary 不可达（系统太慢/太贵/太危险）
- 状态→响应映射非平稳（如 LLM 的 temperature 随机性——需多 seed；随机性主导时外部观测失去分辨力）

## 5. 与物理测量理论的方法论同构

量子力学的基础问题（波函数不可直接观测，只能通过测量装置）与 LLM 黑盒（内部状态不可直接获得，只能通过 API 观测）在认识论结构上同构。**"测量装置本身需要校准"** 的直觉——正是 VAL 的"锚"与"裁判的裁判"的直觉来源。这是本项目最独特的视角来源。

## 6. 递归层

```
verifier 需要 verifier，audit 需要 audit，裁判永远还有裁判。
```

没有终极裁判；科学需要每一层都清楚声明自己的 anchor、scope、guarantee 和 residual uncertainty。

## 7. 作为研究纲领 vs 作为事实

**当前状态**：这是研究纲领——在 verification、agent security、AI-assisted research 三个领域结构成立，且 JADE 预测卡（5/5 含边界命中）完成了第一个"可证伪预测→验证"的小循环。

**待验证**：这个结构是否能在更多领域（物理实验、软件验证、决策系统）持续产生预测力——是"强结构直觉"还是"跨领域方法论"，需要未来几年验证。**现在不能把后者当成事实。**

## 8. 三句话（最终定论）

> **不要试图消灭黑盒；把黑盒置于一个能产生可验证响应的系统中。**
>
> **不要只看结果；追问结果的来源。**
>
> **不要寻找终极裁判；让每一层裁判诚实地声明自己的边界。**

## 9. 浓缩

> **黑盒不是障碍，是对象；来源不是细节，是证据；边界不是缺陷，是承诺。**
