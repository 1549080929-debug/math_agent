# 05 · 锚定层级：裁判价值的通用判据

> 三章实验沉淀出的**唯一可迁移结论**——不是"LLM 太强"或"裁判有缺陷"这些具体结果，
> 而是"裁判的价值 = 它的规格锚定在哪一层"这个可复用的判据。

---

## 一、问题被问错了

复盘三章所有"裁判没兜住"的失败，摊开后发现**没有一个是裁判判错了**：

| 失败 | 裁判在干嘛 | 真正坏掉的是 |
|---|---|---|
| 拆解层污染 | 忠实验证了被喂错的公式 | 问题本身被 LLM 写错 |
| 组合层篡改 | 子任务全对，终局答案在视线之外被改 | 裁判没看到最终答案 |
| 完备性盲区 | 代回 a=2 判 PASS，完全正确 | 代回验证在原理上证明不了"没漏" |
| 信任递归 | 按 LLM 声明的 final_check 判，判对了 | 规格本身是 LLM 编的 |

裁判的精度是 34→42/42（数学）、3/3（医疗）。**它是一台校准合格的仪器，只是被指向了错误的对象、或压根没被指向。** 所以该追责的不是裁判，是**规格的锚定来源**。

## 二、锚定层级（L0–L3）

| 层级 | 锚定来源 | 强度 | 项目里的例子 |
|---|---|---|---|
| **L0** | LLM 声明规格 | 最弱（信任递归） | 实验七的 final_check 由 LLM 写 |
| **L1** | 题面规则派生 | 中（确定性，但依赖题面表述） | 实验八的正则提取 final_check |
| **L2** | 客观地面真值 | 强（不依赖题目本身） | 标准答案 SymPy 审计、实测值、外部 oracle |
| **L3** | 定义性/证明性地面真值 | 最强（性质编码进可判定系统） | 类型检查、解集等价、闭式解、已验证的临床决策规则 |

**规律**：项目的失败几乎全在 L0/L1；有效的那几次（#105、[-1,1]→[0,1]、Δ 纠错）都锚在 L2/L3。这不是巧合——裁判的价值由它锚定的层级决定。

## 三、完备性不是"做不到"，是"必须换范式"

代回/抽样验证在原理上不完备，**但这不等于"完备性无解"**。完备性可以拿到——前提是把问题**重新编码**到一个性质可判定的领域：

- 一元二次函数"求所有 a"：用闭式解 / `solveset`（符号完备解器），而不是代回抽样。你第一章的问题是**把一个可完备的问题，主动降级成了不可完备的抽样验证**。
- 医疗"结论超出证据"：用**已验证的临床决策规则**（Alvarado/Wells/PERC/CURB-65/HEART），完备性来自规则的穷举结构。
- 行为"输出层无痕迹的攻击"：这才是真正无解的那一类——它连可判定的锚都找不到。**这才是"完备性盲区"该有的精确含义**：不是"代回验证不完备"，而是"该性质无法编码进任何可判定系统"。

> 一句话规律：**你放弃"任意性质"，换取"某个性质上的完备性"——这是所有 L3 锚的共同代价。**

## 四、前例（同构的成熟实践）

1. **证明助手（Coq/Lean/Isabelle）**：人写规格，机器检查证明，裁判归约到极小的可信内核。完备性是**构造出来**的（一个通过类型检查的证明程序 = 完备证明）。"裁判的裁判"= 内核，且小到可被完整审计——这是让信任递归**收敛封底**的方式。
2. **类型系统（Rust borrow checker）**：证明"无 use-after-free / 数据竞争"是对**所有路径**的完备保证，代价是限制语言表达力。
3. **临床决策规则（Wells/PERC/Alvarado/CURB-65/HEART）**：被验证的、确定性的、锚定在客观输入的规则。PERC 规则字面意思就是"全阴性 → 可安全排除 PE"——一个**完备性方向**的保证。
4. **计量溯源性（NIST 校准链）**：测量逐级溯源到原始基准（由约定定义），**每一层锚定在更外层**，而不是停在"这台仪器说它对"。

## 五、可操作的判据

对每一个"要不要建裁判"的决策，先问一句话：

> **"这个失败模式，有没有一个 L3 级的锚，能把'正确性'升级成'完备性'？"**
> - 有 → 建裁判（**导入或重编码，别自造**）；
> - 没有 → 这个裁判最多是 L1/L2 的"可信度探针"，别指望它闭合，诚实标注为边界。

## 六、本次落地（2026-08-18）

给第一章裁判新增 `solution_set` 验证类型（L3 完备性锚）：

- 用 `solveset` 求**完备真解集**，与声称解集做集合相等比较；
- 直接抓到代回验证（`verify_root`）抓不到的三类错误：**漏解**（`"2"` vs `{2,3}`）、
  **漏负根**（`"sqrt(3)"` vs `{±√3}`）、**压缩篡改**（`"a=0 或 a=2"` vs `[0,2]`，P5 模式）；
- 裁判单元测试 **34 → 42**，全部通过。

这印证了判据本身：**同一个"求所有解"任务，换一个 L3 锚，完备性盲区就从"原理无解"变成"可判定"。** 完备性的边界不是固定不变的，它随锚定层级的抬高而收缩。
