## 2. 增强路线图（按杠杆排序）

### 杠杆 1：未对齐攻击者（最大杠杆）
- **内容**：Groq 免费 Llama-3.3-70B 作为攻击者（对齐服从度高于本地 8B；拿到 key 即可复用 attacker_client 接线）
- **假设**：可能打破 N 的半配合墙（ASR 升）→ 运气声称从"两家族拒答"升级为"愿意的攻击者实测"；V 应依然 0
- **验收**：白盒自适应 N+V × 30 场景；任一结果都推进结论（命中=运气实锤；不中=墙更硬）
- **风险**：Groq 免费档额度/模型可用性——备选 Together/Fireworks 托管 Llama

### 杠杆 2：AgentDojo 真 harness 集成（可信度杠杆）
- **内容**：把 V/N 栈接到 AgentDojo 真实任务环境（pip install agentdojo，DeepSeek 作 agent），跑其官方攻击与评估
- **作用**：把"自建测试床 + 外部锚对比表"升级为"第三方基准上的实测"——直接拆掉审稿第一枪
- **验收**：AgentDojo 基准上 V 栈 ASR/utility 至少不劣于其报告的最佳防御
- **风险**：AgentDojo 官方支持 OpenAI 系 API，DeepSeek 需适配（其 pipeline 可配置 base_url——有 OpenAI 兼容层，可行性中高）；集成工作量 2-4 周

### 杠杆 3：2×2 多 seed（低成本加固）
- **内容**：Llama 受害者 3 seed（现为单次）；DS 受害者补 3 seed（已有 3 seed 主配置）
- **验收**：σ 报告入论文 §6.4
- **成本**：Llama 本地 ~30 分钟/配置

### 杠杆 4：P02 SLR 对话节（审稿防御）
- **内容**：§2.2 后加一小节：与 Source-of-Authority SLR 的逐点对照（同轴、异排序、无 Q2/Q3）——审稿人若知此文，主动对位显专业
- **验收**：1 页内

### 杠杆 5：良性扩样（可选）
- Llama 受害者良性已 20；如需更紧 CI 可扩到 30（成本低）
