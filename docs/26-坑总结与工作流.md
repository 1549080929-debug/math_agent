## 一、表格管线坑（2026-08-22 新增，最值钱）

### 坑 1：pandoc 表格 + l 列 = 表格超宽溢出页面
- **现象**：全部 6 个表格 Overfull \hbox 946–2348pt，正文/附录表格溢出页面右边界
- **机制**：pandoc 把 markdown 表转 longtable 时**每个单元格包 `\begin{minipage}[b]{\linewidth}`**；fix_latex.py 重生成列格式为 `l`×N 后，**l 列中 `\linewidth` = 整个 `\textwidth`**（约 512pt），每列都是一个 512pt 宽的盒子 → 表格总宽 ≈ N×512pt
- **修复**：列格式改 `tabularx{\textwidth}{XXX...}`（X 列等分，minipage 自动适配列宽）
- **信号（三层验证，缺一不可）**：
  1. xelatex 日志 `Overfull \hbox` 警告（第一信号）
  2. pymupdf 文本 bbox maxR > 页面宽（595.3pt）
  3. **渲染 PNG + PIL 右边缘暗像素 > 0（视觉真相——pypdf 提取文本 ≠ 视觉，会因内容在页面外而漏检）**

### 坑 2：tabularx 里 l/c 列 + minipage = X 列被挤成 0、行高爆炸
- **现象**：Level map 表首列改 l 后，行高暴增 250pt、溢出页底（文本 y=849 > 页高 842）
- **机制**：tabularx 计算列宽时，l/c 列内 minipage{\linewidth} = \textwidth（449pt），剩余宽度为负 → X 列退化为 0 宽 → 内容逐字竖排
- **修复**：窄列用 **`p{宽度}`**（p 列正确设置 `\linewidth` = 列宽，minipage 自动适配）。Level map 表 = `p{1.2cm}XXX`
- **规则**：**tabularx 中绝不用 l/c 列放 minipage 结构；要么全 X 等分，要么 p{宽度} + X**

### 坑 3：Python 正则 `\r` 是回车符
- `BS + 'raggedright'`（BS=反斜杠）在正则里 = `\r`（回车符）+ aggedright，匹配永远失败
- **修复**：用 raw string：`r'\\raggedright\s*Level\s*\\end\{minipage\}'`

### 坑 4：CRLF vs LF（Windows）
- 仓库文件多为 CRLF，Edit 工具精确匹配失败（报 "old_string not found"）
- **修复**：用 Python io 读写（`newline=''`）做替换，或 Edit 前先确认行尾

### 坑 5：PowerShell 5.1 环境
- 不支持 `&&`（用 `;`）；嵌套引号常报 ParserError；GBK 控制台打印 Unicode 报 UnicodeEncodeError
- **修复**：`py -X utf8 -c "..."` 强制 UTF-8；复杂逻辑写脚本文件再执行

## 二、ARR 投稿坑（本会话核实）

1. **"ARR 2026-12" 周期不存在**——ARR 2025-05 起 10 周一轮（一年 5 轮）；最近窗口 2026-10-12（October 2026 周期）→ meta 12-20 → 2027-01 承诺 ACL 2027。官方日期必须 curl 直连 aclrollingreview.org/dates 核实
2. **双盲匿名化**：`build_arr.py` 里 `\author` 是**硬编码**（改 paper_arr.md 不够）；自引 bib 条目要 `author={Anonymous}, note={Under review}`（官方示例格式）+ 去掉 eprint；arXiv 自引号必须从摘要删（一搜即中）
3. **Limitations 章节硬性要求**：无则 desk reject（本论文 §8 已有，合规）
4. **Responsible NLP checklist 必填**：AI 助手使用必须披露（匿名版无致谢 → 在 checklist 里披露）
5. **l 列表格 + minipage 在投稿版同样存在**（本论文 6 个表格全中招）

### 纪律（HANDOFF §7 精炼版）
1. 审计先行 · 每步提交推送 · claim 边界画在证据边界上
2. **改 md 必须重跑全管线**（rebuild_full.py），下游产物会 stale
3. **pypdf 提取 ≠ 视觉**：表格/页面检查 = 日志 Overfull + bbox 界内 + 渲染 PNG 像素三重验证
4. **tabularx 规则**：全 X 等分 或 p{宽度}+X；绝不用 l/c 列放 minipage
5. TinyTeX ASCII 路径（C:\TinyTeX）
6. anchor 必须唯一（'not the hit count.' 出现过误删）
