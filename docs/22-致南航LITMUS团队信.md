您好！我是殷亚杰，南通大学物理师范专业本科生，独立研究者，研究方向是 LLM 验证与智能体安全防御的失败模式。拜读了贵团队的 LITMUS 论文（arXiv:2605.10779）后，我确信我们的工作存在一个罕见的**独立互证**关系，值得向您汇报并探讨合作。

**一、我对贵团队工作的理解**

LITMUS 是第一个在真实 OS 环境中系统评测 LLM agent **行为越狱**的基准：语义-物理双层验证机制 + OS 状态回滚 + 819 个高风险用例（CVE/GHSA 等来源）覆盖越狱修辞、技能注入、实体包装三种攻击范式。两个核心发现尤其重要：

1. 即便最强安全意识的模型（Claude Sonnet 4.6）仍执行 **40.64%** 的高风险 OS 操作；
2. **Execution Hallucination（EH）普遍存在**——agent 口头拒绝请求，但危险操作已在系统层面静默完成，对一切语义层评估框架完全不可见。

**二、我们的工作：一个独立的、结论相同的发现**

我提出的 VAL 框架（Verification Autonomy Levels，arXiv:2608.19009）按"验证/防御规格的来源"给验证方案分级：L0 模型自述（运气）、L1 确定性规则、L2 客观真值、L3/L4 可判定系统。核心论点是：**验证锚决定能验证什么**——语义/输出层的锚结构上无法捕获物理层已发生的行为。

在框架的第一篇论文（第三章行为观测）中，我们独立发现了与贵团队 EH 高度同构的现象——**covert execution（隐匿执行）**：模型执行了注入指令但在输出中不留下任何痕迹。我们的实证结果是：所有输出层特征集对该现象的检测率 TPR 仅为 **0.60**，我们将其定位为"输出层锚的 L2 结构天花板"。

| 维度 | 我们（paper1，arXiv:2608.19009） | LITMUS（arXiv:2605.10779） |
|---|---|---|
| 现象 | covert execution：执行但输出无痕迹 | Execution Hallucination：口头拒绝但系统层静默执行 |
| 测量 | 输出层检测 TPR 0.60 | EHR 7.98%–17.97% |
| 定位 | 输出层锚的 L2 结构天花板 | 对一切语义层框架不可见 |

两个独立团队、不同的技术路线（统计检测 vs 真实 OS 双层验证），收敛到**同一个结论：语义层的验证锚存在结构盲区，物理层行为必须用物理层锚验证**——这正是 VAL 框架的核心论点，贵团队用工程实证把它推到了真实 OS 环境。

**三、合作建议**

1. **论文互引/联合工作**：EH 与 covert execution 的独立复现，对两个工作都是有力的外部验证。VAL 可以给 LITMUS 的双层验证机制分级（语义层=L0 锚、OS 物理层=L2 锚），为"为什么 EH 会发生"提供理论解释。
2. **防御互测**：我们在 AgentDojo 官方基准和复旦 JADE 实例上验证过一个"确认门+参数沙箱"防御栈（0% ASR、零 utility 损失）。LITMUS 的 819 个 OS 用例是更严苛的行为安全测试床——我们愿意把防御栈接到 LITMUS 评估框架上，验证结构防御在真实 OS 层面的价值。
3. **指标互补**：贵团队的 EHR 与我们的"合规率/半配合"测量关注同一光谱的两端（"说不做但做了" vs "被驱动但没做成"），合并分析可以给出更完整的"语义-物理错位"图景。
