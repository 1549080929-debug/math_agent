## 1. 三篇全文精读

### P01 Injection-Execution Dissociation（arXiv:2605.08442）

**核心**："提示注入成功"（写入记忆，>97.5%）与"工具执行成功"（实际外泄，0–95%）**无相关**。防御跨四层：输入（Sanitizer）88.9% ASR、检索（RAG Judge）88.9%、指令（Prompt Hardening）77.8%、工具（Memory Sandbox）**11.1%**（但 qwq:32b 反转至 100%）。**层级位置而非分类器质量决定成败**。中间态原型：Latent Carrier（100% 注入/0% 执行）、Partial Executor、Draft-Only——即"提议但未执行/半配合"。

**对我们的印证**：
1. **双指标必要性被独立确认**——作者明言注入/执行成功率应分开报告，"混淆会掩盖真实安全态势"。我们的"合规率 vs ASR"不是过度设计，是领域共识。
2. **中间态原型 = 我们的空 args 半配合**（D1 的 61 例高危+空参数）。
3. **防御反转警示**：qwq:32b 在 Memory Sandbox 下 ASR 0→100%（推理模型用 RAG 回退绕过工具门控）——结构防御必须**真正无 LLM 环节**。我们的 D4 是纯确定性（无 LLM 回退），风险低，但这条警示值得写进 agentsec 报告的边界。
4. 方法学警示：空语料库产生假阴性（0/210）——我们的 stub executor 无此问题，但真实部署需注意。

**可引用**：Table 5 层级框架、Defense Attribution / Retrieval-Fidelity 效度准则。

### P02 Source-of-Authority SLR（arXiv:2607.05031）——独立收敛，最重要的一篇

**核心**：PRISMA 2020，2436→54→83 篇。三轴：**source**（7 值：spec-derived / impl-derived / reference-differential / model-parametric / human-elicited / regression / implicit）、form、mechanism。关键发现：
- **过半语料（42/83）无需外部规格**即可裁决——"无锚验证"的实证；
- **source × mechanism 正交**："LLM-as-a-judge 说的是判定怎么产生，不是为什么该信它"——这句话几乎是我们论文五轴混淆节的原文；
- 评估多重"近似已知 oracle"，仅 13 例用变异注入测故障捕获（≈ 我们的"完备性盲区"）。

**与 VAL 的映射**：source 轴 ≈ 我们的 Q1（spec→truth/decidable；model-param→LLM；human→rule）；**他们无 Q2（保证类型）无 Q3（完备性）无等级排序**（作者明言"来源排序是概念主张而非实证结果"）。

**意义**：这是**锚定轴的独立收敛**——一个与我们无关的团队，用系统综述走到了同一个轴。我们的论文不再是"一个人的直觉"。v2/v3 必须引用；方向 3 论文把它列为最接近的相关工作。他们的 7 值 source 可以细化我们的 4 值 Q1（如 reference-differential ≈ 我们的"执行结果锚"，implicit ≈ L0 的变体）。

### P07 When Does Verification Pay Off?（arXiv:2512.02304）

**核心**：37 模型（0.5B–72B）× 9 基准。**verifier gain** = 过滤后正确率提升（rejection sampling 增益的渐近上界）。发现：
- **self/intra-family 增益最小，cross-family 最大**——verifier 与 solver 解分布越相似，误收错误解越多（FPR 升）；
- **自发自验率**：Qwen3 96%、DeepSeek 73%——强推理模型已自验，额外验证几乎无增益；
- 任务层面：可多项式验证的属性（3SAT/Sudoku）验证收益高；无捷径属性（矩阵乘法）无收益。

**对我们的修正**：
1. 我们的"准确率窗口空"（数学/医疗/代码）被细化为 **"self/intra 窗口空"**——cross-family 验证仍有效。论文 v2 的"窗口空"表述应加这个限定。
2. **判级研究的诚实性修正**：我们的 B 系列评分者全是同一 LLM——κ 0.8 是 **intra-family 一致性**。P07 说同族一致性高估可靠性。docs/11 的结论应标注"同族一致性"，异族评分者（Claude/GPT 系）是下一步。
3. agentsec 的 N 栈 D1 = self-verification（同模型自评安全）——P07 解释了它为什么不可靠（同族 FPR 高）。

## 3. 横切结论（三条）

1. **锚定轴被独立收敛**：P02（83 篇 PRISMA）走到"权威来源"轴，P01（5040 run 实验）走到"注入 vs 执行"分离——我们的核心直觉不再是孤证。**这是把 VAL 从"概念主张"升级为"被独立验证的轴"的关键外部证据。**
2. **同源验证的极限被多路确认**：P07（self/intra 增益趋零）、P08（相关误差理论）、P01（防御反转）、我们的 B 系列（同族 κ 0.8）——"LLM 裁判是 L0"有了外部理论+实验支撑。
3. **部署价值问题正在被领域围攻**：P07 问"何时值回票价"、P01 问"防御放在哪层"——我们的 agentsec 实验处在正确的战场。但 **P07 提示我们的度量也要升级**：用 verifier gain（过滤后提升）而不是验证准确率衡量判级价值。
