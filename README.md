# math_agent — 带确定性裁判的多步数学推理代理

> **一句话**：LLM 只做翻译，SymPy 做裁判，类型系统管组装，终局验证兜底。
>
> 通过 8 轮"直觉 → 架构 → 实验 → 被证伪"的循环，产出两份东西：
> ① 一套可复现的 **LLM 多步推理失败模式分类学**（8 个模式，全部有数据实证）；
> ② 一个诚实的**分层信任架构**（每一步都标明"谁验证了什么、没验证什么"）。

---

## 核心主张

> 在数学这类封闭形式系统里，LLM 的自然语言生成与逻辑必然性存在本体论冲突。
> 因此：**推理链上的每一层都必须挂接可验证的裁判，而裁判必须理解"完备性"而不只是"正确性"。**
> 数学只是试验场——这套"规划-验证-反馈"分层指向的是通用 AI 多步推理架构。

## 架构

```
题目 → [入口分类] → [拆解] → [自查] → 逐个子任务(求解→SymPy验证→反馈纠错→回溯)
      → [组合(结构化输出)] → [终局验证(规格由题面规则派生)] → 输出 + 可信度标记
```

关键设计：
- **三态裁判**：PASS / FAIL / UNSURE（不懂就弃权，不误杀）
- **类型系统**：答案类型声明与反查，跨类型转换报错
- **终局验证**：最终答案集合抽样验证，FAIL → 修正循环 → 诚实失败
- **规格规则派生**：终局验证条件从题面正则提取，不依赖 LLM 声明
- **诚实失败**：`answer_verified` 与 `ok` 严格分离，不把未验证答案当结果

## 快速开始

```bash
# 1. 配置密钥：local_config.json（不入 git）或环境变量 DEEPSEEK_API_KEY
# 2. 安装依赖
pip install -r requirements.txt

# 3. 裁判单元测试（无需 API）
python test_verifier.py        # 34/34

# 4. 跑一道题
python main.py -p "求函数 f(x)=x^2-4x+7 在区间 [1,4] 上的最小值"

# 5. 批量跑 20 题测试集
python run_testset.py          # 结果存 data/testset_results.json
```

Windows 下可双击 `run.bat`。

## 实验结果摘要（诚实版）

| 实验 | 系统 | baseline | 要点 |
|---|---|---|---|
| 基础 5 题 | 5/5 | 5/5 | 简单题无优势 |
| 对抗预测 5 题 | 3/5 | 5/5 | 预测 0/5 应验；**标准答案 3/5 是错的** |
| 20 题×3 轮 | 16/15/13 | 20/20 | 价值窗口为空；准确率是随机变量 |
| 压轴 2 题 | 0/2 | 2/2 | 拆解污染 + 组合篡改 |
| 类型系统+终局验证 | — | — | B 题 [-1,1]→[0,1] 当场抓获修正；裁判 34/34 |

**诚实定位**：在 deepseek-chat + 一元二次函数范围内，架构的准确率不优于 baseline。
架构的价值在**可验证性、诚实性、失败分类学**——"系统知道自己没验证什么"。

## 目录结构

```
math_agent/
├── main.py                # 主流程（分类→拆解→验证→纠错→组合→终局验证）
├── verifier.py            # 裁判：8 种验证类型，三态
├── decomposer.py          # 入口分类 + 拆解 + 自查
├── solver.py              # 子任务求解 + 反馈纠错
├── combiner.py            # 组合（结构化输出，按验证状态如实标注）
├── final_check_deriver.py # 终局验证规格规则派生
├── llm_client.py          # DeepSeek 客户端
├── config.py              # 配置（密钥外置）
├── test_verifier.py       # 34 个裁判用例
├── audit_*.py             # 标准答案审计（审计先行）
├── run_testset.py         # 20 题测试集运行器
├── baseline.py            # baseline（直接求解）
├── data/                  # 全部实验数据
├── docs/                  # 四份核心文档
└── logs/                  # 运行痕迹（经验库地基）
```

## 已知边界（简版）

1. **完备性盲区**：采样/代入验证无法证明"没有遗漏"——原理性开放；
2. **价值窗口**：当前模型/题型范围内架构准确率不优于 baseline；
3. **反馈纠错不稳定**：同一模型自我修正的方差大；
4. **验证规格地面真值**：规则派生覆盖 6/20，其余靠 LLM 兜底。
